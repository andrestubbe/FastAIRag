TITLE:
FastAIRag: JMH Benchmark - End-to-End Microsecond RAG Pipeline ⚡

DESCRIPTION:
Official OpenJDK JMH (Java Microbenchmark Harness) performance benchmark for FastAIRag. Measuring total end-to-end latency across layout ingestion, SIMD chunking, vector match, and LLM parent context prompt synthesis.

BENCHMARK RESULTS (JMH):
- Full Document Ingestion: 5-10 ms (Visual Paragraph Parse)
- SIMD Child Match & Parent Retrieval: < 500 µs
- End-to-End Context Builder: Sub-millisecond prompt injection

RUN BENCHMARK LOCALLY:
Execute `run-benchmark.bat` in the repository root.
